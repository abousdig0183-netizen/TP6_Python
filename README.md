# TP6 – Dataclasses et Tests Unitaires

## Objectif
Utiliser les dataclasses pour simplifier la création des classes et tester leur fonctionnement.

## Notions abordées
- Décorateur `@dataclass`
- Attributs et méthodes
- Classes immuables avec `frozen=True`
- Optimisation avec `slots=True`
- Comparaison des objets
- Validation des données
- Sérialisation JSON
- Tests unitaires

## Projet
Gestion d'une classe Film.

## Fichiers
- `film.py`
- `test_film.py`

## Exécution
```bash
python film.py
python -m unittest test_film.py
